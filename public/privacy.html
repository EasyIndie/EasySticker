隐私政策

最后更新：2026 年 6 月 3 日

我们非常重视您的隐私。本隐私政策说明 EasySticker 在您使用本服务时如何收集、使用、存储和保护您的信息。

一、数据收集

在使用 EasySticker 的过程中，我们可能会收集以下类型的数据：

  • 上传的参考图片 — 您上传用于生成表情包的原始图片（PNG、JPG、WebP 等格式）。
  • AI 生成结果 — 系统通过 AI 模型处理后生成的表情图、封面、图标、横幅及赞赏图等资源。
  • 配置信息 — 您输入的提示词、风格选择、表情包标题、作者名及版权信息等元数据。
  • 使用日志 — 匿名化的操作记录（如上传时间、生成次数、错误类型），用于改善服务质量。

我们不会主动收集您的姓名、地址、电话号码、地理位置或设备标识符等个人身份信息，除非您通过邮箱注册账户时主动提供。

二、数据存储与安全

所有数据均存储于您所部署的本地服务器中：

  • 存储位置 — 上传的图片和生成结果存储在服务器 data/ 目录下。
  • 临时存储 — 所有文件均设有时效缓存（TTL），默认 1 小时后自动清理。
  • 存储期限 — 生成结果在服务器端仅临时保留，下载后请自行妥善保存。
  • 传输安全 — 建议通过 HTTPS 部署本服务以保障数据传输过程中的安全性。

EasySticker 是自托管（self-hosted）应用，数据不会离开您自己的服务器。如果您使用第三方部署平台，请同时参考该平台的数据安全策略。

三、Cookie 与本地存储

EasySticker 不使用传统 HTTP Cookie。我们使用浏览器的 localStorage 存储以下信息：

  • 主题偏好（theme） — 记录您选择的亮色/暗色模式。
  • 身份令牌（token） — 登录后用于维持会话状态，不包含密码或其他敏感信息。

您可以随时通过浏览器开发者工具清除 localStorage 数据，这不会影响应用的核心功能。

四、第三方共享

我们不会将您的数据出售、共享或披露给第三方。

由于 EasySticker 是自托管应用：

  • 您上传的图片和生成的内容仅存在于您自己的服务器上。
  • 我们不使用第三方分析服务、广告网络或社交媒体追踪脚本。
  • 如果使用了远程 AI 模型 API 服务（如 OpenAI、ComfyUI），相关数据将按该服务商的隐私政策处理。建议您在使用前查阅对应服务商的隐私条款。

五、用户权利

根据适用的数据保护法规，您享有以下权利：

  • 访问权 — 您可以要求了解我们收集了哪些与您相关的数据。
  • 删除权 — 您可以要求删除您的账户及相关数据。
  • 撤回同意 — 您可以随时停止使用本服务，已上传的临时数据将在 TTL 到期后自动清理。
删除账户请求：如需删除账户及相关数据，请联系管理员处理。联系邮箱请参见服务页面或服务器部署说明。

六、政策更新

我们可能会不时更新本隐私政策。重大变更时，我们会通过服务页面公告或更新页面顶部「最后更新」日期的方式通知您。建议您定期查阅本页面以了解最新信息。

七、联系我们

如果您对本隐私政策有任何疑问或担忧，请通过以下方式联系我们：

  • 在部署服务器上查阅项目 README 或联系服务器管理员。
  • 如为开源部署，欢迎在 GitHub 项目仓库中提交 Issue。
